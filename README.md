# ThreatLens

ThreatLens is a Python-based web security analysis tool being developed from scratch as a long-term cybersecurity project.

The project starts with URL management and basic URL checking, and will gradually evolve into a modular web security analysis and scanning tool.

## Current Status

🚧 Under Development

## Current Features

- Single URL input
- Multiple URL input
- URL validation
- File-based URL importing
- Basic error handling
- Basic URL checking structure
- Modular Python architecture
