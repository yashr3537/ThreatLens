# SentinelX

SentinelX is a Python-based web security analysis tool being built from scratch as a long-term cybersecurity project.

The project starts with basic URL management and will gradually evolve into a web security scanner capable of analyzing website responses, security configurations, and potential security issues.

## Current Status

🚧 Under Development

### Current Features

- Add URLs
- Save URLs to files
- Search URLs from files
- Basic URL management

### Planned Features

- URL validation
- HTTP response checking
- HTTP status code analysis
- Response-time measurement
- Redirect detection
- HTTP security header analysis
- CORS analysis
- Cookie security analysis
- Technology detection
- Endpoint discovery
- Security findings
- JSON/TXT reports
- OWASP-based security checks
- CLI interface

## Technology

- Python
- HTTP/HTTPS
- JSON
- File handling
- Web security concepts

## Project Goal

The goal of SentinelX is to build a practical web security analysis platform while understanding and implementing each component from the ground up.

## Development Approach

SentinelX is being developed incrementally.

Each major feature is implemented, tested, documented, and committed separately so that the complete development history remains clear.

## Disclaimer

SentinelX is intended for authorized security testing, learning, and defensive security analysis only.

Do not scan websites or systems without proper authorization.
